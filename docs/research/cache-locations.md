Date: 2026-10-16. Output: `targets-batch2.json` (115 rules, ids unique against `rules/targets.json` and `rules/artifacts.json`). Generated by `gen_batch2.mjs`, checked by `validate_batch2.mjs` (structure, lexical guard copy, overlap with shipped rules, UTF-8 without BOM).

The batch was also merged with the shipped catalog in a scratch copy of `crates/core`, and `cargo test -p reclaim-core --lib` passed (30 tests, including `builtin_rules_parse_and_validate` and `builtin_rule_paths_pass_the_guard`). Nothing under `C:\Projeler\pc-cleaner` was edited.

## How sure each rule is

- `verified: true`: a vendor page or the project's own source code names the location. Every source URL was fetched and returned 200, except bot-protected pages (helpx.adobe.com, help.evernote.com, answers.ea.com and minecraft.wiki return 403 to scripts but exist).
- `verified: false`: the path comes from the app's standard layout (Chromium or Electron cache folders inside a known app data folder), from read-only inspection of a local install, or from community sources. 60 of the 115 rules are unverified. Unverified rules that touch anything other than plain caches or logs are `review` or stricter.
- Rules citing `github.com/MoscaDotTo/Winapp2` (11 rules: Xbox app, Steam extras, NVIDIA app, AMD Software, Amazon Games) are based on read-only inspection of local installs; Winapp2 is cited only as a second opinion. Winapp2 is CC-BY-SA-4.0. Only the fact that a folder exists was used; no entries were copied. If you prefer not to link it, swap the source for a vendor page when one exists.
- The web-search budget ran out during the research. Items that could not be checked afterwards were left out rather than guessed (listed under each platform).

## Notes for existing rules (not changed)

1. **`user-temp` can delete recovery files.** It deletes everything in `%TEMP%` older than 24 hours. That includes:
   - Krita autosaves of never-saved images (`.krita-<pid>-*-autosave.kra`). Krita docs warn about exactly this: https://docs.krita.org/en/user_manual/autosave.html
   - Blender's `quit.blend`, which File > Recover > Last Session opens. Blender docs warn that cleanup tools delete it: https://docs.blender.org/manual/en/latest/troubleshooting/recover.html
   - Gradio's `%TEMP%\gradio`, which Gradio never cleans by default. For some AI web UIs it is the only copy of generated images.
   - Stable Diffusion WebUI's `tmp*.png` outputs.

   Consider an exclusion list for that rule (`*.kra`, `*.blend`, `quit.blend`, `gradio`). That needs either a new `exclude` field or engine support.
2. **`arc-cache` is correct.** It already uses the MSIX path `Packages\TheBrowserCompany.Arc_*\LocalCache\Local\Arc`, which is where Arc really stores data.
3. **Paths covered by existing rules and therefore not added again:**
   - winget's download temp `%TEMP%\WinGet`, Chocolatey's download cache `%TEMP%\chocolatey`, Photoshop scratch files `%TEMP%\Photoshop Temp*` and Blender `%TEMP%\*.crash.txt`. All of these are inside `%TEMP%`, which `user-temp` covers.
   - The TensorFlow Hub cache `%TEMP%\tfhub_modules` and the PyTorch CUDA kernel cache `%TEMP%\torch\kernels`, also in `%TEMP%`.
   - VS Code `.obsolete`: VS Code deletes the listed folders itself.

- iCloud: no vendor documentation found. Messenger desktop was shut down in December 2025.
- Netflix, Disney+ and Prime Video: their downloads are DRM-protected user content, and no cache folders are documented.

## Games and GPU tools

**Added**
- EA app:
  - `ea-app-logs` (safe, verified): the user `Logs` folder.
  - `ea-app-cache` (safe): CEF `BrowserCache\EADesktop\{Cache,Code Cache,GPUCache,DawnCache}`, `IGOCache`, and the `qmlcache` folders.
  - `%PROGRAMDATA%\EA Desktop\Logs` was left out: it is read-only for Users, and the folder is small.
- Origin:
  - `origin-cache` (safe): only `Web Cache`, `ImageCache` and `AvatarsCache`. EA's old advice to delete `%LOCALAPPDATA%\Origin` would also delete `Cloud Saves`, which many installs have.
  - `origin-local-content` (report).
- `ubisoft-connect-cache` (safe):
  - Only `cache\http*`, `cache\assets` and `cache\telemetry`, plus `logs`.
  - Ubisoft's article renames the whole cache folder, but the rule keeps `ownership` (offline licenses) and `Installers`.
  - `savegames` is a sibling of `cache` and is never touched.
- `gog-galaxy-cache` (review): `logs`, `crashdumps`, and the artwork subfolders of `webcache`.
- `xbox-app-cache` (safe): `Logs`, `DiagOutputDir`, `ImageCache`, `TempState`, and the EBWebView caches in the GamingApp package.
- Minecraft:
  - `minecraft-logs` (safe): `logs`, `crash-reports`, the launcher `webcache2\Default` caches, and CurseForge instance logs.
  - `minecraft-launcher-logs` (files): `launcher_log*.txt` and `launcher_cef_log*.txt`.
- Other launchers:
  - `prism-launcher-cache` and `modrinth-app-cache` (from their source).
  - `curseforge-app-cache`.
  - `playnite-cache` (`PlaynitePaths.cs`).
  - `itch-app-cache` and `heroic-logs`.
  - `amazon-games-logs`.
- `roblox-logs-downloads` (safe):
  - `Roblox\logs` (Bloxstrap source confirms it).
  - `Roblox\Downloads`.
  - `Bloxstrap\Downloads` (Bloxstrap's package cache).
  - `LocalLow\RbxLogs`.
- Steam (default folder only):
  - `steam-download-leftovers` (safe): `steamapps\temp` and the Workshop `downloads` and `temp` folders.
  - `steam-partial-downloads` (review): `steamapps\downloading`.
  - `steam-redownloadable-caches` (review): `package`, `depotcache` and `appcache\librarycache`. The next start needs a network connection.
- NVIDIA:
  - `nvidia-app-logs` (files `*.log` and `*.log.bak`).
  - `nvidia-app-web-cache` (CefCache).
  - `nvidia-driver-downloads` (review, admin, 72 h): `UpdateFramework\ota-artifacts`, often several gigabytes, and the GFE `Downloader`.
  - `nvidia-system-logs` (admin, 24 h).
- AMD: `amd-software-cache` (Qt shader caches in `Radeonsoftware\cache`) and `amd-software-logs` (`RSX_Common.log_*.log` in `AMD\CN`).
- `overwolf-logs` (verified): `%LOCALAPPDATA%\Overwolf\Log`.

**Excluded**
- Saves: Ubisoft `savegames`, `.minecraft\saves` and `backup`, Bedrock `com.mojang`, Origin `Cloud Saves`, EA `cloudsync`, and the Rockstar `Profiles` folders.
- Installs: Ubisoft `games`, itch `apps`, `C:\XboxGames`, `steamapps\common`, and Roblox `Versions`.
- Licenses and sign-in:
  - EA `EA Services\License` and `OfflineCache`.
  - Steam `appinfo.vdf`, `packageinfo.vdf` and `config\*.vdf`.
  - Minecraft `launcher_msa_credentials` and account files.
  - Ubisoft `user.dat` and `ownership`.
  - Every Chromium `Network`, `Local Storage`, `IndexedDB` and `Login Data` folder.
- `%PROGRAMDATA%\EA Desktop` as a whole: forum posts suggest deleting it, but it holds `InstallData` and `machine.ini`.
- GOG `redists`, `support`, `storage` and `config.json`.
- NVIDIA:
  - `NGX\models` (DLSS models).
  - `Drs` (3D settings).
  - `Installer2`: needed to repair and uninstall NVIDIA components.
  - Recordings.
- AMD:
  - `CN\*.blb`: the game databases and the recordings gallery.
  - `RGStats.db`, and `PPC` (purpose unclear).
  - The `NewsFeed`, `gameicon_cache` and `Temp` folders: guesses only.
- Rockstar Launcher: its logs are in Documents, which is protected, and there is no vendor cache article.
- TLauncher: an unofficial launcher. It keeps world backups in `.minecraft\backup` (these can reach many gigabytes).
- Minecraft Bedrock (GDK): no log path verified. The only official cleanup is in-game: Settings > Storage > Clear Marketplace Cache.
- Shader caches of individual games (Battlefield, CoD): not vendor-documented, and some are in Documents.

## Browsers

**Added** (each rule uses the same cache folder set as the shipped Chromium and Firefox rules)
- `chrome-channels-cache`: Chrome Beta, Dev, Canary and Chrome for Testing. The paths are listed verbatim in Chromium's `user_data_dir.md`.
- `edge-channels-cache` (unverified): Edge Beta, Dev and Canary (`Edge SxS`).
- `brave-channels-cache`: Brave Beta, Dev and Nightly. Install suffixes come from `chromium_install_modes.h`.
- `thorium-cache`.
- `yandex-cache` and `coccoc-cache`: both browsers use `browser.exe`, so either one blocks the other's rule.
- `whale-cache`.
- Firefox forks: `waterfox-cache`, `librewolf-cache`, `floorp-cache`, `zen-cache` and `palemoon-cache`. Only the local profile root is used: `cache2`, `startupCache`, `thumbnails` and `shader-cache`.
- `thunderbird-cache`: only `cache2` and `startupCache` in the local profile. Mail lives in Roaming and is never touched.
- Floorp's profile name comes from `MOZ_APP_PROFILE "Floorp"` in its `moz.configure`. Zen's folder is `%LocalAppData%\Zen`, per BleachBit's cleaner.

**Excluded**
- Tor Browser and Mullvad Browser: they are portable and keep no disk cache, and their Data folder holds Tor state and bridges.
- Opera Beta and Developer, Cent, Comodo Dragon, Epic, Helium, Iridium and Sidekick: niche or unverified.
- Every roaming profile, which holds bookmarks, passwords and cookies.
